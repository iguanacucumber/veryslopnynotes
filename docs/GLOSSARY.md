# GLOSSARY.md — acronymes du dépôt

Un sigle, une phrase, le document qui fait autorité. Les liens sont relatifs à
ce fichier.

| Acronyme | Définition |
|---|---|
| ADR | Décision d'architecture consignée et datée dans [`docs/adr/`](adr/), qui explique le pourquoi d'une règle du dépôt. |
| APK | Paquet Android installable produit par le build debug ou release et décrit dans [`docs/RELEASE.md`](RELEASE.md). |
| DCO | Developer Certificate of Origin, attestation par `Signed-off-by` exigée sur chaque commit et décrite dans [`CONTRIBUTING.md`](../CONTRIBUTING.md#dco-sign-off). |
| ENT | Espace Numérique de Travail, portail scolaire dont le SSO n'est pas pris en charge, listé dans [`docs/COMPATIBILITY.md`](COMPATIBILITY.md). |
| MFA | Authentification multifacteur, non prise en charge par l'app, listée dans [`docs/COMPATIBILITY.md`](COMPATIBILITY.md). |
| PIN | Code saisi par l'utilisateur pour déchiffrer en mémoire le jeton porté par le QR, décrit dans [`docs/COMPATIBILITY.md`](COMPATIBILITY.md#connexion--qr-uniquement). |
| QR | QR code de l'application Pronote qui porte l'adresse, le login et le jeton de session, décrit dans [`docs/COMPATIBILITY.md`](COMPATIBILITY.md#connexion--qr-uniquement). |
| SSRF | Server-Side Request Forgery, risque borné par la garde et la politique d'égression du scraper dans [`docs/architecture/SERVER-EGRESS.md`](architecture/SERVER-EGRESS.md). |
| TTL | Durée de vie d'une entrée de cache par ressource, décrite dans [`docs/PRODUCT.md`](PRODUCT.md). |
| WebView | Moteur Chromium système qui affiche le bundle React embarqué, décrit dans [`docs/adr/004-webview.md`](adr/004-webview.md). |
